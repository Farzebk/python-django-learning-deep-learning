# Python → Django → AI Agent Engineer

A personal learning journey from frontend development to
full-stack Python/Django and AI agent engineering.

The goal is not just to learn syntax or follow tutorials,
but to understand the codebase I work with well enough to
read, debug, explain, modify, and eventually design parts
of it independently.

## 🧠 Study Method

For every topic:

**Learn → Practice → Apply → Explain → Document → Commit**

### Rules

- Use AI as a tutor, not a code generator.
- Try to understand code before asking AI.
- Find existing examples in the real codebase.
- Retype important code from memory.
- Keep a confusion log.
- Use the debugger instead of blindly adding print statements.
- Commit meaningful learning milestones.
